## 13. Side-by-Side Comparison against Claude Code & OpenCode

| Dimension | Claude Code | OpenCode | Redesigned Nomin Code | Comparison Finding |
| :--- | :--- | :--- | :--- | :--- |
| **Startup Overhead** | ~400ms (Node bundle + Ink + Yoga) | ~30ms (Bun/Solid) | **<15ms (Native Node VT engine)** | **BETTER:** Nomin Code launches instantly without React/Yoga reconciler overhead. |
| **Model Selection** | In-prompt text picker | `DialogModel` modal | **Virtualized arrow-key picker with live query & detail bar** | **BETTER:** Zero typed numbers, live fuzzy search across 100+ NIM models with Tab category cycling. |
| **Streaming Latency** | Slight redraw lag on conhost | Very smooth | **Zero input lag (incremental ANSI flush)** | **PARITY:** Identical smooth streaming with animated cursor block `▋`. |
| **Permission Modes** | `Shift+Tab` cycles modes | Manual auto-approve flags | **`Shift+Tab` cycles Normal ➔ Auto-Accept ➔ Plan Mode** | **PARITY:** Matches Claude Code's signature keyboard shortcut. |
| **Tool Call Formatting**| Collapsible one-liners | Collapsible cards | **Collapsed one-liners with duration and tab expand** | **PARITY:** Eliminates visual border pollution. |
| **Multi-Agent Swarm** | Single agent + subagents | Single session + tabs | **5 Swarm Agents (Architect, Coder, Tester, Reviewer, Verifier)** | **BETTER:** Native horizontal role bar and shared blackboard. |
| **Remaining Weakness** | Rich image paste rendering in terminal | Full desktop integration | Terminal image rendering not supported in text-only terminals | **REMAINING WEAKNESS:** Text-only fallback for multimodal image inputs on standard Windows PowerShell. |
